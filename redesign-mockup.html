What changes from today

  • Tabs are gone. The 4-tab layout (Available / Protected / Blacklist / Auto-Discard) collapses into one view. Each filter in the sidebar shows its own hidden-item count (e.g. In Gearset · 23 hidden) — no separate "Protected Items" surface in the main pane.
  • Lists popup (📋 in toolbar) shows the blacklist and auto-discard list side-by-side, every entry visible with item icon, name, item-level, and a × to remove. Each side has a search/add field at the top. Auto-discard items currently in inventory are flagged with [in inventory]. ImGui: ImRaii.PopupModal with two ImRaii.Child columns.
  • Column headers at the top of the item list label every number — Item, Qty, iLvl, Unit price, Total value. Stays visible while scrolling. ImGui: a fixed row above the scrolling category tree, or use ImGui.TableHeadersRow() if migrating each category to a Table.
  • Sidebar holds every "what to show" toggle — display options (armory, prices) at the top, then the 9 filters. Toolbar is navigation only: search, refresh, world, lists, settings, gil total. Kills the vertical real-estate the current FilterPanelComponent eats. ImGui: ImRaii.Child with fixed width.
  • Floating selection bar only appears when items are selected — no permanent bottom bar. Three primary actions instead of five. ImGui: render conditionally above the item list when SelectedCount > 0.
  • Hover quick-actions per row: blacklist / auto-discard / discard appear inline only on hover. Cuts the “select → scroll → bottom button” workflow to one click. ImGui: ImGui.IsItemHovered() + SameLine + SmallButton.
  • Right-click context menu on any row covers all per-item operations: blacklist, auto-discard, search market, highlight, discard. ImGui: ImGui.OpenPopupOnItemClick("ctx", ImGuiPopupFlags.MouseButtonRight).
  • Settings popup (⚙ in toolbar) holds passive-discard config and market-price settings only. Removes the inline passive-discard section from the main UI. ImGui: ImGui.OpenPopup + ImRaii.PopupModal.
  • Status bar at the bottom replaces noise that was previously inline (passive-discard status, last Universalis fetch). ImGui: a final ImRaii.Child at fixed height.

What stays the same

  • Color palette is the existing UI/Theme.cs verbatim.
  • Tree of categories & items uses ImRaii.TreeNode just like today.
  • Item table can keep using the existing ItemTableComponent — only its column config changes (smaller, hover-action column).
  • Blacklist & auto-discard data, persistence, and InventoryState wiring don’t change at all. This is purely a UI rework on top of the existing services.
